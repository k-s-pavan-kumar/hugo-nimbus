Nimbus is a Tailwind CSS Hugo theme built for DevOps knowledge hubs —
blog posts, sidebar-navigation docs, Architecture Decision Records, and
native OpenAPI reference docs, all in one theme.

This site is the theme's `exampleSite` — a working demo you can build
locally to see every feature in context, and a template for your own site.

## What's demonstrated here

- **[Blog]({{< relref "/blog" >}})** — a standard post feed with tags,
  categories, related posts, and social sharing.
- **[Documentation]({{< relref "/docs" >}})** — sidebar-navigation docs with
  a version switcher, table of contents, and a full
  [shortcode reference]({{< relref "/docs/shortcodes" >}}).
- **[Architecture Decision Records]({{< relref "/adr" >}})** — a
  purpose-built content type for tracking infrastructure decisions.

See the [Installation]({{< relref "/docs/installation" >}}) guide to use
Nimbus on your own site.
